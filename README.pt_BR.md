# Soc Ops

> **Transforme pequenas conversas em jogo.** Soc Ops é uma experiência rápida de bingo social para encontros presenciais, em que as pessoas circulam pelo ambiente, encontram alguém que combine com cada pergunta e correm para completar **5 em linha**.

Construa uma experiência divertida para eventos **e** aprenda a desenvolvê-la com o **modo agente do GitHub Copilot**.

## ✨ Por que Soc Ops?

Soc Ops é um projeto de workshop que mistura **pensamento de produto no mundo real** com **desenvolvimento assistido por IA**:

- **Para quem joga:** um quebra-gelo leve e social que faz todo mundo se movimentar, conversar e rir.
- **Para desenvolvedores:** um lab prático para construir com **FastAPI, Jinja2, HTMX e Pydantic**.
- **Para participantes do workshop:** uma forma prática de explorar o **modo agente do GitHub Copilot**, design de prompts, fluxos multiagente e iteração orientada a design.

> Pense nele como um jogo pequeno com lições surpreendentemente ricas sobre design de produto, arquitetura backend, UX frontend e colaboração com IA.

## 🕹️ Como Jogar

1. **Inicie um jogo** e compartilhe a cartela com as pessoas do encontro presencial.
2. Cada casa contém uma pergunta ou prompt social, como encontrar alguém com uma curiosidade, experiência ou preferência específica.
3. As pessoas **conversam com quem está no ambiente** e marcam as casas quando encontram alguém que combine.
4. O objetivo é completar **5 em linha** — na horizontal, vertical ou diagonal — antes das outras pessoas.
5. O resultado é um quebra-gelo simples que transforma apresentações em uma missão divertida.
