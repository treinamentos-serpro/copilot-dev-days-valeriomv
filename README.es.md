# Soc Ops

> **Convierte la charla inicial en un juego.** Soc Ops es una experiencia rápida de bingo social para encuentros presenciales, donde las personas recorren la sala, encuentran a alguien que encaje con cada pregunta y compiten por completar **5 en línea**.

Construye una experiencia divertida para eventos **y**, al mismo tiempo, aprende a desarrollarla con el **modo agente de GitHub Copilot**.

## ✨ ¿Por qué Soc Ops?

Soc Ops es un proyecto de workshop que combina **pensamiento de producto del mundo real** con **desarrollo asistido por IA**:

- **Para quienes juegan:** un rompehielos social y ligero que hace que todos se muevan, conversen y se diviertan.
- **Para desarrolladores:** un laboratorio práctico para construir con **FastAPI, Jinja2, HTMX y Pydantic**.
- **Para asistentes del workshop:** una forma concreta de explorar el **modo agente de GitHub Copilot**, el diseño de prompts, los flujos multiagente y la iteración guiada por diseño.

> Piensa en Soc Ops como un juego pequeño con lecciones sorprendentemente ricas sobre diseño de producto, arquitectura backend, UX frontend y colaboración con IA.

## 🕹️ Cómo se Juega

1. **Inicia una partida** y comparte el tablero con las personas del encuentro presencial.
2. Cada casilla contiene una pregunta o prompt social, como encontrar a alguien con una experiencia, preferencia o dato curioso concreto.
3. Las personas **hablan con otras en la sala** y marcan casillas cuando encuentran una coincidencia.
4. El objetivo es completar **5 en línea** — horizontal, vertical o diagonal — antes que los demás.
5. El resultado es un rompehielos simple que convierte las presentaciones en una misión divertida.
